# kalimat Notes and Bibliography (CSL)

The Zotero citation style of the journal _kalimat_, for articles that cite Arabic- and Latin-script sources.

## Use

- **Zotero desktop:** download `kalimat-notes-and-bibliography.csl` and open it with Zotero.
- **Zotpress / Zotero API:** use the file's raw URL as the style:

  ```
  https://raw.githubusercontent.com/kalimaat/kalimat-csl/main/kalimat-notes-and-bibliography.csl
  ```

  The URL always serves the current version.

The style chooses the Arabic or Latin-script layout from each record's **Language** field: `ar-Arab` for Arabic-script records, `ar-Latn` for transliterated Arabic, and a language tag such as `en`, `de` or `fr` for other Latin-script records.

## Updates

This repository is updated automatically whenever the style changes. Please don't edit it here; changes would be overwritten. Report problems to the _kalimat_ editorial team.
